# CAH Asistencia Android

Aplicación Android nativa del Colegio de Arquitectos de Honduras (Java y SQLite).

## Compilación

El flujo de GitHub Actions `Compilar APK Android de CAH` genera un **APK de depuración para pruebas**, descargable desde la pestaña Actions cuando la compilación finalice correctamente. Para su publicación institucional se recomienda un APK de lanzamiento firmado y pruebas reales.

## Seguridad

No publicar información real de empleados ni contraseñas. La base de datos se almacena en el Android. El repositorio contiene únicamente el código fuente, sin datos personales.

Consulta `LEEME_PRIMERO.md` y `PRUEBAS.md`.
